# PodBrain Phase 2 Roadmap — Testing, Debugging & Launch Finalization

**Date:** 2026-02-27
**Prerequisite:** All 8 phases of the launch roadmap are feature-complete (98 items implemented)
**Current state:** 0 TypeScript errors, 513 unit/integration tests passing
**Goal:** Get PodBrain from "feature-complete" to "production-ready"

---

## Overview

The codebase has ~240 files implementing 48 API routes, 16 pages, 27 components, 17 hooks, and 82 lib modules. Everything compiles. But the gap between "compiles" and "works in production" is significant. This roadmap covers that gap.

**Estimated timeline: 3-5 weeks**

## Quick Reference: What's Definitely Untested

These modules have zero test coverage and are high-risk:

1. **Trigger.dev jobs** — The entire processing pipeline (`process-episode.ts`, `transcribe-audio.ts`, `generate-show-notes.ts`, `generate-assets.ts`, `post-transcription-pipeline.ts`)
2. **Taddy client** — GraphQL client, caching, rate limiting
3. **Podcasting 2.0 generators** — Tag generation, VTT, RSS snippets
4. **Expert discovery** — Taddy-backed discovery rewrite
5. **Webhook dispatcher** — HMAC signing, HTTP delivery
6. **Circuit breaker** — State transitions, recovery
7. **Tier enforcement** — Limit checking, upgrade prompts
8. **Auth middleware** — Session refresh, protected routes
9. **RSS parser** — Feed parsing, edge cases
10. **Team management** — Invites, seat limits, RLS
