# Security Hardening Summary

**Branch:** `security/hardening`
**Date:** 2026-03-05
**Commits:** 8
**Files changed:** 30 (692 additions, 747 deletions)

## Process

Three parallel security audits (codebase cartographer, manual review, adversarial scrutiny with 7 agents) identified vulnerabilities across input validation, error leakage, rate limiting, AI prompt injection, HTTP headers, dependency vulnerabilities, and Stripe checkout hardening. The scrutiny process returned a MODIFY verdict with 8 incorporated modifications that deflated scope and corrected regression risks.

## Changes Made

### 1. Error Message Sanitization (22 API routes)

Replaced `error.message` leakage in 500 responses with generic "Internal server error" messages. Server-side `console.error()` preserved for debugging. Preserved the RSS import 422 response (`Failed to parse RSS feed: ...`) as legitimate UX feedback.

### 2. HTTP Security Headers

**`next.config.ts`:**
- `X-Frame-Options: DENY`
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Strict-Transport-Security: max-age=63072000; includeSubDomains` (no preload — premature for pre-launch)
- `Permissions-Policy: camera=(), microphone=(), geolocation=()`
- `X-XSS-Protection: 1; mode=block`
- `Content-Security-Policy-Report-Only` (see CSP section below)
- `poweredByHeader: false`

**`netlify.toml`:** HSTS and X-XSS-Protection added to match.

### 3. Stripe Price ID Injection Fix

Removed the `body.price_id` fallback in `POST /api/stripe/checkout`. Price IDs now derive exclusively from server-side tier-to-priceId lookup via `getServerPriceId(tier, interval)`. Users can only pass `tier` (from allowlist) and `interval`.

### 6. AI Prompt Injection Sanitization

Wired `sanitizeForAI()` from `lib/sanitize.ts` to all surfaces where user-controlled metadata is interpolated into LLM prompts:

| File | Fields Sanitized |
|------|-----------------|
| `lib/content/generator.ts` | episodeTitle, showName, guestName, guestBio |
| `lib/xai/prompts.ts` | episodeTitle, guestName, targetKeywords |
| `api/episodes/[id]/pre-interview/route.ts` | guestName, guestBio, topics |
| `api/episodes/[id]/ab-test/route.ts` | showName, currentValue, guestName, description |

**Transcript content is intentionally NOT sanitized** — it's machine-generated by AssemblyAI, and `sanitizeForAI()` would corrupt legitimate words like "system" and "instruction".

### 7. Content Security Policy (Report-Only)

Added `Content-Security-Policy-Report-Only` header allowing:
- `script-src`: self, unsafe-inline/eval (Next.js), js.stripe.com, posthog
- `connect-src`: self, *.supabase.co, api.stripe.com, *.sentry.io, *.posthog.com
- `frame-src`: self, js.stripe.com
- `img-src`: self, data, blob, *.supabase.co
- `object-src`, `base-uri`, `form-action`, `frame-ancestors`: locked down

**Timeline:** Monitor violations for 30 days before considering enforcement.

## Accepted Risks

| Risk | Mitigation | Rationale |
|------|-----------|-----------|
| SSRF via RSS import | Netlify serverless limits blast radius | No private network access from serverless |
| File type MIME bypass | Supabase Storage non-execution guarantee | Storage serves files with `Content-Disposition: attachment` |
| happy-dom RCE | Dev-only dependency, not in production bundle | Only used in `vitest` test environment |
| HSTS preload omission | HSTS enabled with 2-year max-age | Preload is a permanent commitment; re-evaluate after 6+ months |

## Deferred Items

| Item | Reason |
|------|--------|
